EXHIBIT 09 — THE INVESTIGATION PAYS OFF

Same key. Same IV. Reversed.

The material recovered in Exhibit 06 wasn't just an explanation — it was a working decryption key. Running AesCryptoServiceProvider in reverse with the same constants turned .fun files back into what they used to be.

encrypted.funRead ciphertext, apply the recovered key + IV.
AES-128-CBC (decrypt)Reverse of the exact routine found inside Locker.
original filename restoredThe .fun suffix is stripped and the file is rewritten in place.
decryption.ps1
$root = Read-Host "Root directory to scan"

$key = [Convert]::FromBase64String("OoIsAwwF23cICQoLDA0ODe==")
$iv  = [byte[]](0,1,0,3,5,3,0,1,0,0,2,0,6,7,6,0)

$files = Get-ChildItem -Path $root -Filter "*.fun" -File -Recurse
Write-Host "[*] Found $($files.Count) encrypted files."

foreach ($file in $files) {
    $outputPath = [IO.Path]::Combine($file.DirectoryName, $file.BaseName)
    $ciphertext = [IO.File]::ReadAllBytes($file.FullName)

    $aes = New-Object System.Security.Cryptography.AesManaged
    $aes.Key = $key
    $aes.IV  = $iv
    $decryptor = $aes.CreateDecryptor()

    # first 16 bytes are a discardable header the sample prepends
    $plaintext = $decryptor.TransformFinalBlock($ciphertext, 16, $ciphertext.Length - 16)

    [IO.File]::WriteAllBytes($outputPath, $plaintext[16..($plaintext.Length - 1)])
    Write-Host "[+] $($file.FullName) -> $outputPath"
    $aes.Dispose()
}

Write-Host "[+] Decryption scan completed."

EXHIBIT 11 — WHAT THE INVESTIGATION REVEALED

The full chain, laid out.

01Suspicious executableFlagged on intake, before any code was traced.
02.NET / Confuser32-bit managed binary under a standard obfuscator.
03DeobfuscationControl-flow and strings recovered to readable IL.
04LockerThe class responsible for touching victim files.
05AESAesCryptoServiceProvider, called with static parameters.
06Hard-coded key + IVThe single point of failure in the entire scheme.
07.fun extensionThe visible marker of an encrypted file.
08Original file deletionThe irreversible half of the attack — everything before this was recoverable.
09RecoveryThe same key, run backward, closed the case.

Jigsaw looked chaotic from the outside.

But malware rarely stays mysterious once you follow the evidence.

Static clues led to behavioral evidence. Behavior led to code. Code revealed the cryptographic mechanism. And the cryptographic mechanism made recovery possible.
